# LegiSchola

Agentic AI law-school companion, starting with institution-first onboarding.

## Stack
Next.js (App Router), TypeScript, Supabase, Netlify.

## Local setup
1. `npm install`
2. Copy `.env.example` to `.env.local` and supply the Supabase publishable key.
3. `npm run dev`
